C AKTIVITAS 1 — EKSPERIMEN 10 + 20

Prediksi hasil sebelum menjalankan kode. Jalankan kode dan amati. Simpan file sebagai lkpd_string_number_aira.js.

Jangan jalankan terlebih dahulu. Prediksikan hasil:

lkpd_string_number_aira.js 
let a = "10";
            let b = "20";
            console.log(a + b);
Pertanyaan Jawaban Kamu
Apa output program? 1020
Mengapa hasil tersebut terjadi? Karena variabel a dan b diapit tanda kutip ("...") sehingga dibaca sebagai tipe data String (teks). Operator + pada String berfungsi untuk menggabungkan teks (concatenation), bukan menjumlahkan angka.
Apakah a dan b bertipe Number? Tidak, keduanya bertipe String.
Uji sekarang. Apakah prediksimu benar? Jelaskan.

Benar. Setelah kode dijalankan di console/terminal, output yang muncul adalah 1020. Hal ini membuktikan bahwa JavaScript menggabungkan teks "10" dan "20" secara berdampingan karena keduanya bertipe String, bukan melakukan operasi aritmatika penjumlahan.

D AKTIVITAS 2 — MENEMUKAN TIPE DATA

Jalankan kode berikut untuk memeriksa tipe datanya:

cek_tipe_data.js 
let nama = "aira";
let umur = 16;
console.log(typeof nama);
console.log(typeof umur);
Variabel Prediksi Hasil typeof Kesimpulan
nama string string Nilai yang diapit tanda kutip ("Asep") otomatis dikenali JavaScript sebagai tipe data String.
umur number number Nilai angka murni tanpa tanda kutip (16) dikenali sebagai tipe data Number.
Temuan: Apa perbedaan String dan Number berdasarkan eksperimenmu?

String adalah tipe data untuk teks/karakter yang penulisannya wajib diapit tanda kutip ("..." atau '...') dan tidak bisa dihitung secara matematis dengan benar. Sedangkan Number adalah tipe data khusus angka yang ditulis tanpa tanda kutip dan dapat digunakan dalam operasi matematika (tambah, kurang, kali, bagi).

G TANTANGAN — PROGRAM HITUNG NILAI

Buat program dengan input nilai tugas, UTS, dan UAS. Konversikan semua input menggunakan Number(), lalu hitung rata-rata dengan rumus (tugas + UTS + UAS) / 3.

Algoritma saya:
  1. Meminta pengguna memasukkan nilai Tugas melalui prompt() dan langsung mengonversinya menjadi tipe data angka menggunakan Number().
  2. Meminta pengguna memasukkan nilai UTS dan UAS melalui prompt(), serta mengonversi masing-masing menjadi Number.
  3. Menghitung nilai rata-rata dengan rumus (tugas + uts + uas) / 3 dan menyimpannya ke dalam variabel rataRata.
  4. Menampilkan hasil akhir nilai rata-rata ke layar menggunakan console.log().
hitung_nilai.js (Kode Program) 
let tugas = Number(prompt("Masukkan nilai Tugas:"));
let uts = Number(prompt("Masukkan nilai UTS:"));
let uas = Number(prompt("Masukkan nilai UAS:"));

let rataRata = (tugas + uts + uas) / 3;
console.log("Nilai Rata-rata Anda adalah: " + rataRata);

H THINK PAIR SHARE

Pertanyaan Jawaban
Mengapa prompt() perlu dikonversi jika hasilnya ingin dihitung? Karena fungsi prompt() selalu mengembalikan data bertipe String meskipun pengguna mengetikkan angka. Agar bisa dihitung secara matematis, data tersebut harus diubah dulu ke tipe Number.
Apa perbedaan "10" dengan 10? "10" (pakai kutip) bertipe String (dianggap karakter teks), sedangkan 10 (tanpa kutip) bertipe Number (dianggap nilai bilangan/angka).
Apa yang terjadi jika lupa Number()? Pada operasi penjumlahan (+), angka-angka tidak akan dijumlahkan melainkan digabung menjadi teks panjang (contoh: "80" + "90" menjadi "8090"), sehingga hasil perhitungan menjadi salah/bug.
Pair & Share:

Pair (Bandingkan jawaban dengan teman. Apakah sama? Mengapa bisa berbeda?):
Secara garis besar jawabannya sama, yaitu tentang pentingnya konversi tipe data sebelum berhitung. Perbedaannya hanya pada cara penyampaian kalimat dan contoh angka yang digunakan saat menjelaskan.


Share (Sampaikan satu temuan penting kepada kelas):
