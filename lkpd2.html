Petunjuk

  • Kerjakan berurutan.
  • Jalankan setiap kode dan amati hasilnya.
  • Pahami fungsi setiap baris, jangan sekadar menyalin.

Aktivitas 1 - Prediksi

let a = 10;
let b = 5;
console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
Operasi Prediksi Hasil sebenarnya
a + b 15 15
a - b 5 5
a * b 50 50
a / b 2 2

Apakah prediksi kamu benar? Ya / Sebagian / Tidak

Mengapa? Karena operator +, -, *, dan / pada JavaScript bekerja sesuai aturan matematika dasar (penjumlahan, pengurangan, perkalian, dan pembagian) terhadap nilai variabel a = 10 dan b = 5.

Aktivitas 2 - Eksperimen

let a = 20;
let b = 4;
console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a % b);

Prediksi & Hasil:

  • a + b = 24
  • a - b = 16
  • a * b = 80
  • a / b = 5
  • a % b = 0

Apa yang kamu temukan? Operator % (modulus) menghasilkan sisa dari pembagian. Karena 20 habis dibagi 4, maka sisa pembagiannya adalah 0.

Aktivitas 3 - Input dengan prompt()

let nama = prompt("Masukkan nama:");
console.log(nama);
let umur = prompt("Masukkan umur:");
console.log(umur);

Apa fungsi prompt()? Fungsi prompt() digunakan untuk menampilkan kotak dialog input kepada pengguna agar pengguna dapat memasukkan data melalui keyboard, lalu menyimpannya ke dalam variabel.

Aktivitas 4 - Menghitung Umur

let tahunLahir = prompt("Masukkan tahun lahir:");
let tahunSekarang = 2026;
let umur = tahunSekarang - tahunLahir;
console.log(umur);

Uji dengan tahun lahir kamu (contoh: 2010):
tahunLahir: 2010
Umur = 16 tahun

Aktivitas 5 - Mesin Kasir Mini

let harga = prompt("Masukkan harga:");
let jumlah = prompt("Masukkan jumlah:");
let total = harga * jumlah;
console.log(total);

Uji: Harga = 5000, Jumlah = 4 → Total = Rp 20.000 (20000)

Aktivitas 7 - Challenge: Warung Digital

Buat program yang meminta nama makanan, harga, dan jumlah. Tampilkan nama, harga, jumlah, dan total. Kembangkan dengan diskon 10%, lalu tampilkan Total, Diskon, Total Bayar.

Kode Lengkap (Termasuk Diskon 10%): 
let makanan = prompt("Nama makanan:");
let harga = Number(prompt("Harga:"));
let jumlah = Number(prompt("Jumlah:"));

let total = harga * jumlah;
let diskon = total * 10 / 100;
let bayar = total - diskon;

console.log("Nama Makanan:", makanan);
console.log("Harga Satuan:", harga);
console.log("Jumlah Beli:", jumlah);
console.log("Total Harga:", total);
console.log("Diskon (10%):", diskon);
console.log("Total Bayar:", bayar);

Aktivitas 8 - Debugging

let harga = 5000;
let jumlah = 3;
let total harga = harga jumlah;
console.log(total harga);

Kesalahan:

  1. Nama variabel total harga menggunakan spasi (seharusnya digabung atau menggunakan camelCase seperti totalHarga).
  2. Tidak ada operator perkalian (*) di antara harga dan jumlah.

Perbaikan kode:

let harga = 5000;
let jumlah = 3;
let totalHarga = harga * jumlah;
console.log(totalHarga);

Aktivitas 9 - Challenge Mandiri: Kalkulator Tabungan

Buat program yang meminta uang awal, tabungan hari pertama, kedua, dan ketiga, lalu menghitung total.

Kode Program (Menggunakan Number() agar dijumlahkan sebagai angka): 
let uangAwal = Number(prompt("Masukkan uang awal:"));
let hari1 = Number(prompt("Tabungan hari pertama:"));
let hari2 = Number(prompt("Tabungan hari kedua:"));
let hari3 = Number(prompt("Tabungan hari ketiga:"));

let totalTabungan = uangAwal + hari1 + hari2 + hari3;
console.log("Total tabungan = Rp " + totalTabungan);

Contoh Hasil: Jika uang awal 10.000, hari ke-1 = 5.000, hari ke-2 = 5.000, hari ke-3 = 10.000 → Total tabungan = Rp 30.000

C. BAHAN AJAR

1. Mengingat Variable

Variable adalah tempat untuk menyimpan data.

let nama = "Budi";
let umur = 17;
let nilai = 85;

2. Input - Process - Output

INPUT → PROCESS → OUTPUT

let harga = 5000;
let jumlah = 3;
let total = harga * jumlah;
console.log(total);

3. Output dengan console.log()

console.log("Halo");
let nama = "Budi";
console.log(nama);
console.log("Nama saya adalah", nama);

4. Input dengan prompt()

let nama = prompt("Masukkan nama:");
console.log(nama);

Alur: Pengguna mengetik → prompt() → variable → console.log().

5. Operator Aritmatika

Operator Fungsi Contoh Hasil
+ Penjumlahan 10 + 5 15
- Pengurangan 10 - 5 5
* Perkalian 10 * 5 50
/ Pembagian 10 / 5 2
% Sisa pembagian 10 % 3 1

6. Variable dalam Perhitungan

let nilai1 = 80;
let nilai2 = 90;
let total = nilai1 + nilai2;
console.log(total);

7. Contoh Kehidupan Nyata

Harga satu buku Rp10.000 dan membeli 3 buku:

let harga = 10000;
let jumlah = 3;
let total = harga * jumlah;
console.log(total); // Hasilnya 30000

8. Pola Dasar Program

let data1 = ...;
let data2 = ...;
let hasil = data1 OPERASI data2;
console.log(hasil);

// Contoh:
let panjang = 10;
let lebar = 5;
let luas = panjang * lebar;
console.log(luas);

9. Catatan tentang prompt()

Hasil prompt() secara umum diterima sebagai teks/string. Untuk mengubahnya menjadi angka dapat digunakan Number().

let angka = Number(prompt("Masukkan angka:"));
